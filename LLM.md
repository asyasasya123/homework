Мой вопрос: Как работает git push, опиши когда его надо использовать и зачем?

```
Ответ: git push — это команда для отправки локальных коммитов в удалённый репозиторий.
git push <remote> <branch>
# Пример: git push origin main
Когда использовать git push
1. После локальных коммитов
2. Публикация новой ветки
3. Синхронизация изменений
4. Обновление pull request
Зачем использовать git push
1. Бэкап и сохранность кода

Ваш код сохраняется не только локально

Защита от потери данных при сбоях

2. Совместная работа

Команда видит ваши изменения

Возможность code review

Интеграция изменений разных разработчиков

3. Непрерывная интеграция (CI/CD)

Автоматические сборки и тесты запускаются после push

Автоматическое развертывание
```

Я задала запрос в Deepseek и он подсказал, что для начала нужно использовать git add <smth> и git commit -m "whatever" и только потом использовать git push
