# homework

## What this code does?
It creates file out.txt with shoutout 

## How to run it?
get git project
```
git clone https://github.com/asyasasya123/homework.git
cd homework
```
activate snakemake env
``` 
conda activate snakemake-env
```
get output file 
```
snakemake --cores 1
type out.txt
```
